# 내 업무일지 · 시장조사 아카이브

날짜별로 업무 메모를 적고, 검색과 태그로 다시 찾아보는 개인 업무일지 페이지입니다.

- `index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 쓸 수 있습니다.
- 기록은 브라우저에 저장되고, Claude Artifact로 배포해서 열면 계정에 저장되어 기기를 옮겨도 그대로 보입니다.

## 기능

- 날짜 · 제목 · 내용 · 태그로 기록 작성, 수정, 삭제
- 내용 / 제목 / 태그 통합 검색 (검색어 강조 표시)
- 태그 필터, 자주 쓴 태그 바로 넣기
- 전체 기록 수, 이번 주 기록 수, 연속 기록일 집계
- 밝은 화면 / 어두운 화면 자동 전환, 휴대폰 화면 대응
- `⌘/Ctrl + Enter` 저장, `Esc` 수정 취소

## 시장조사 아카이브 (`market.html`)

시장조사 자료를 기준일별로 쌓아서, 같은 지표가 시간에 따라 어떻게 움직였는지 보는 페이지입니다.

- 기록 한 건 = 기준일 · 시장/주제 · 지표 · 값 · 단위 · 출처(링크) · 메모 · 태그
- **시장 + 지표 + 단위**가 같은 기록은 하나의 시계열로 묶입니다. 입력란의 자동 완성으로 이름을 똑같이 맞추세요.
- **지표 추이**: 지표마다 최신값, 직전 대비 · 처음 대비 변화, 추이 차트(마우스를 올리면 값과 출처 표시), 표 보기
- **기록 타임라인**: 월별로 정리된 전체 기록. 값 없이 메모만 남긴 정성 자료(경쟁사 동향 등)도 여기 쌓입니다.
- **이어 적기**: 기존 기록의 시장 · 지표 · 단위 · 출처를 불러와 다음 측정값만 적으면 됩니다.
- **CSV 내보내기 / 가져오기**: 엑셀에서 열 수 있고, 같은 `id`의 줄은 덮어써서 중복 없이 합쳐집니다.
  열: `date, market, metric, value, unit, source, url, note, tags, id` (`date`, `market`만 필수, 태그는 `;`로 구분)
